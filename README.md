# BHM AI — Backend সেটআপ গাইড

এই ফোল্ডারে BHM AI-এর নিরাপদ backend সার্ভার এবং frontend (public/index.html) আছে।
এখন API key ব্রাউজারে না থেকে সার্ভারে নিরাপদে সংরক্ষিত থাকে।

এই ভার্সনটি **Google Gemini API** ব্যবহার করে, কারণ এর একটি স্থায়ী ফ্রি টায়ার আছে
(ক্রেডিট কার্ড লাগে না)। প্রতিদিন একটা নির্দিষ্ট সংখ্যক প্রশ্নোত্তর ফ্রিতে করা যাবে।

## ধাপ ১: প্রয়োজনীয় জিনিস
- আপনার কম্পিউটারে **Node.js** ইনস্টল থাকতে হবে (nodejs.org/en/download থেকে LTS ভার্সন)
- একটি ফ্রি Gemini API key

## ধাপ ২: ইনস্টল করুন
টার্মিনাল/কমান্ড প্রম্পট খুলে এই ফোল্ডারে গিয়ে লিখুন:

```
npm install
```

## ধাপ ৩: ফ্রি Gemini API key নিন
1. ব্রাউজারে যান: **aistudio.google.com/apikey**
2. আপনার Google অ্যাকাউন্ট দিয়ে লগইন করুন (Gmail থাকলেই হবে)
3. "Create API key" বাটনে ক্লিক করুন — কোনো ক্রেডিট কার্ড বা বিলিং সেটআপ লাগবে না
4. তৈরি হওয়া key-টা কপি করুন (এটা `AIza...` দিয়ে শুরু হয়)

## ধাপ ৪: API key সেট করুন
1. `.env.example` ফাইলটির একটা কপি বানান এবং নাম দিন `.env`
2. `.env` ফাইল খুলে `your_api_key_here` এর জায়গায় আপনার আসল API key বসান:

```
GEMINI_API_KEY=AIzaxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
MODEL=gemini-2.5-flash
PORT=3000
```

⚠️ `.env` ফাইলটি কখনো কারো সাথে শেয়ার করবেন না বা GitHub-এ আপলোড করবেন না।

## ফ্রি টায়ারের সীমাবদ্ধতা জেনে রাখুন
- প্রতি মিনিটে ও প্রতিদিনে একটা রিকোয়েস্ট-সংখ্যার লিমিট আছে। অ্যাপ খুব বেশি ব্যবহার হলে
  মাঝে মাঝে "ফ্রি টায়ারের সীমা শেষ" মেসেজ দেখাতে পারে — এটা স্বাভাবিক, একটু পর আবার কাজ করবে
- Google তাদের মডেল উন্নত করতে ফ্রি টায়ারের প্রশ্ন-উত্তর ব্যবহার করতে পারে (এটা তাদের ফ্রি
  সুবিধার শর্ত) — খুব sensitive/ব্যক্তিগত তথ্য নিয়ে অ্যাপে আলোচনা না করানোই ভালো
- অ্যাপ বড় হলে/বেশি ইউজার হলে ভবিষ্যতে পেইড টায়ারে যাওয়ার প্রয়োজন হতে পারে

## ধাপ ৪: সার্ভার চালু করুন

```
npm start
```

টার্মিনালে দেখাবে: `✅ BHM AI backend চলছে: http://localhost:3000`

## ধাপ ৫: অ্যাপ দেখুন
ব্রাউজারে যান: **http://localhost:3000**

এখন চ্যাট করলে সেটা আপনার নিজের সার্ভার হয়ে API-তে যাবে — API key সম্পূর্ণ নিরাপদ থাকবে।

## ইন্টারনেটে সবার জন্য উন্মুক্ত করতে (Deploy)

লোকাল কম্পিউটারে চালানো মানে শুধু আপনি নিজে ব্যবহার করতে পারবেন। সবার জন্য ওয়েবে আনতে
কোনো একটা হোস্টিং সার্ভিসে এই কোড আপলোড করতে হবে। কয়েকটা সহজ ও ফ্রি/সস্তা অপশন:

- **Render.com** — Node.js অ্যাপ ফ্রি টিয়ারে হোস্ট করা যায়, GitHub রিপো কানেক্ট করলেই ডিপ্লয় হয়ে যায়
- **Railway.app** — সহজ ডিপ্লয়মেন্ট, ভালো ফ্রি ক্রেডিট
- **VPS (যেমন DigitalOcean/Hostinger)** — নিজের সার্ভারে পুরো কন্ট্রোল

যেখানেই হোস্ট করুন, `.env`-এর ভ্যারিয়েবলগুলো (`ANTHROPIC_API_KEY` ইত্যাদি) সেই প্ল্যাটফর্মের
"Environment Variables" সেকশনে বসাতে হবে — `.env` ফাইল কখনো সরাসরি আপলোড করবেন না।

- ইসলামিক বিষয়ের জন্য একটা যাচাইকৃত knowledge base (RAG) যোগ করে নির্ভুলতা বাড়ানো যায়
